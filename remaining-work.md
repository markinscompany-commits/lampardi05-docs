## 18. SEO-проверка и исправления

**Результаты автоматической SEO-проверки (11.04.2026):**

### Критичные проблемы:
- **Robots.txt** — НЕ настроен. URL `/robots.txt` отдаёт HTML главной страницы вместо текстового файла. Поисковые боты не получают инструкций
- **Sitemap.xml** — НЕ настроен. URL `/sitemap.xml` отдаёт HTML. Поисковые системы не видят карту сайта
- **Meta title** — заглушки. Главная = "Главная", /about/ = "Главная", /contacts/ = "Главная". Нужны уникальные title с ключевыми словами для каждой страницы
- **Meta description** — на ВСЕХ страницах стоит `content="Description"`. Не заполнено ни одно
- **Meta keywords** — на всех страницах `content="Keywords"`. Заглушка
- **Open Graph** — полностью отсутствует. Ссылки на сайт в соцсетях не будут показывать превью
- **Страница 404** — отдаёт HTTP 200 и показывает главную. Критично для индексации

### Частично готово:
- **Schema.org** — базовая BreadcrumbList (itemprop) на страницах категорий. Нет Product, нет Organization
- **ЧПУ** — URL читаемые, работают
- **SSL** — работает

### Нужно реализовать:
- Создать и настроить robots.txt (через Битрикс или файлом)
- Настроить автогенерацию sitemap.xml (модуль Битрикс)
- Заполнить meta title / description для всех страниц (главная, категории, товары, О компании, контакты)
- Добавить Open Graph теги
- Добавить микроразметку Product на карточках товаров
- Добавить микроразметку Organization
- Настроить корректный HTTP 404 (см. задачу 9)
- Замерить скорость загрузки (≤3 сек по договору)
- Проверить alt-теги изображений
