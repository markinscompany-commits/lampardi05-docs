#### Примечания

При клике на ячейку в столбце “Правка” откроется страница, в которой будут дополнения к правке с тем, что нужно сделать. Чтобы понять есть ли детали по правке, обратите внимание на иконку документа слева от текста в ячейке. Если на нём есть полоски, значит детали присутствуют. Приложил скрин с примером:

Комментарии

1.1.

Убрать любую анимацию наведения (hover) на всех элементах шапки сайта

Отключить все hover-эффекты на всех элементах шапки. При наведении курсора на любой элемент шапки ничего не должно происходить визуально - никаких подчёркиваний, смены цвета, увеличений и т.д.

- [x] 

1.2.

Скрыть модальное окно каталога при наведении на кнопку «Каталог» в десктопной версии

Сейчас при наведении мыши на кнопку «Каталог» в шапке сайта (десктопная версия) открывается модальное окно со списком категорий (на скриншоте выделено красной рамкой — белая полоса с текстом «ЛЮСТРЫ-ТЕСТ»). Нужно полностью отключить это поведение — при наведении на кнопку «Каталог» модальное окно не должно появляться. Правка касается только десктопной версии.

1.4.

Убрать блюр фона шапки при скролле — заменить на белый фон (#FFFFFF)

Сейчас при скролле страницы вниз шапка сайта становится закреплённой (sticky) и у неё появляется полупрозрачный заблюренный фон (размытие фона). Нужно убрать блюр и заменить фон шапки в состоянии после скролла на сплошной белый цвет #FFFFFF.

1.5.

Кнопка «Поиск» в шапке не работает — по клику ничего не происходит. Нужно сделать рабочей

Критично для MVP. По клику на кнопку «Поиск» в шапке сайта сейчас ничего не происходит. Нужно, чтобы по клику открывалось окно поиска по сайту и поиск работал корректно.
